# BClear Lab — сайт

Лендинг тренажёра британского произношения. Статика: HTML + CSS + немного JS,
без сборки и зависимостей.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `why.html` | Зачем произношение |
| `method.html` | Методика |
| `how.html` | Как работает |
| `faq.html` | Вопросы |
| `early-access.html` | Ранний доступ |
| `404.html` | Страница не найдена (GitHub Pages подхватывает автоматически) |

## Как посмотреть локально

```bash
python3 -m http.server 8000
```

Дальше http://localhost:8000

## Что где

- `assets/site.css` — все стили, дизайн-токены в `:root`
- `assets/site.js` — мобильное меню, шапка при скролле, форма вейтлиста
- `assets/logo-*.svg` — логотип
- `assets/og-source.html` — исходник картинки-превью для мессенджеров (1200×630)

Шрифты: **Jost** (заголовки и кнопки), **Golos Text** (текст), **Noto Sans**
(только транскрипция — в первых двух нет блока IPA).

## Незаполненное

По всему сайту расставлены заглушки с классом `todo`: почта, телеграм, соцсети,
юр. данные, политика конфиденциальности, тарифы, дата запуска и endpoint формы.
Найти все: `grep -rn 'class="todo"' *.html`
