# BClear Lab — сайт

Лендинг тренажёра британского произношения. Статика: HTML + CSS + немного JS,
без зависимостей. Сборка только копирует файлы в `build/` для хостинга.

## Страницы

Каждая страница — папка с `index.html`, адрес заканчивается слешем: `about/index.html`
открывается по адресу `/about/`. Почему так, написано в `DEPLOY.md`.

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `why/` | Зачем произношение |
| `method/` | Методика |
| `how/` | Как работает |
| `faq/` | Вопросы |
| `compare/` | Сравнение с другими приложениями |
| `business/` | Бизнесу: B2B-направление |
| `schools/` | Школам английского: партнерское направление |
| `early-access/` | Лист ожидания |
| `about/` | Обо мне |
| `privacy/` | Политика конфиденциальности (ссылка в футере всех страниц) |
| `consent/` | Согласие на обработку персональных данных (ссылка у галочки в форме вейтлиста) |
| `terms/` | Условия закрытого тестирования сервиса app.bclearlab.ru (ссылка у галочки на странице входа в сервис) |
| `blog/` | Блог: `index.html` и статьи, каждая в своей папке |
| `404.html` | Страница не найдена (хостинг отдает ее для любого несуществующего адреса) |
| `en/index.html` | Английская главная |
| `en/business/` | Английская «Бизнесу» |
| `en/about/` | Английская «Обо мне» |
| `en/early-access/` | Английский лист ожидания |

Внутренние ссылки пишутся со слешем на конце (`/about/`), пути к ассетам — только
от корня (`/assets/...`) на всех страницах: страницы лежат в папках, и путь
`assets/...` уехал бы в несуществующую `/about/assets/`.

## Английская версия

Живет в папке `en/`: `/en/`, `/en/business/`, `/en/about/`, `/en/early-access/`. Переключение —
кнопка с глобусом в меню (`.lang-switch`). С русской страницы, у которой есть
английский двойник, кнопка ведет на него; с остальных — на `/en/`. Обратно
кнопка ведет на соответствующую русскую страницу. На четырех парных страницах
проставлены `hreflang` (`ru`, `en`, `x-default`).

Английские страницы объявляют `<html lang="en">` — по этому атрибуту `site.js`
выбирает язык для сообщений формы вейтлиста и для письма, которое она собирает.

Переведены не все разделы. Ссылки на непереведенные страницы в английском
футере и в блоке под формой вейтлиста помечены `lang="ru"` и подписаны как
русские — так англоязычный посетитель не попадает на русский текст внезапно.
Добавляя новую английскую страницу, не забудьте про `hreflang` на обеих
сторонах пары и про кнопку в меню русского двойника.


## Меню

Пункты «Продукт» и «Бизнесу» — не ссылки, а разделы с выпадающим списком.
Разметка одна и та же:

```html
<div class="nav-group" data-current="true">   <!-- если открыта страница раздела -->
  <button class="nav-group-btn" aria-expanded="false" aria-controls="nav-product">…</button>
  <div class="nav-menu" id="nav-product"> … ссылки … </div>
</div>
```

Состоянием владеет `aria-expanded` на кнопке, и только он: в CSS нет ни
`:hover`, ни `:focus-within`. Иначе на тач-экране список залипал бы открытым
вопреки атрибуту. Правила в `site.js` такие:

- широкий экран с мышью — открывает наведение и клавиатурный фокус, клик по
  самой кнопке ничего не делает. Если бы клик переключал, нажатие по уже
  открытому списку закрывало бы его, а курсор оставался внутри — и обратно он
  бы не открылся;
- тач-экран и узкое меню — открывает нажатие;
- `Escape` закрывает, соседний раздел закрывается сам: два открытых списка
  перекрыли бы друг друга.

Зазор между кнопкой и списком перекрыт псевдоэлементом `.nav-menu::before`.
Без него курсор по дороге к списку оказывается вне группы, и тот закрывается.

Порог переключения на кнопку «Меню» — 1000px, и он продублирован **в трех
местах**: медиазапрос в `assets/site.css`, `matchMedia` мобильного меню и
`matchMedia` выпадающих разделов в `assets/site.js`. Правьте все три сразу.
Горизонтальному меню нужно около 940px ширины окна — если добавляете пункт,
проверьте шапку на 1010px, а не только на своем экране.

Английское меню короче (четыре пункта) и выпадающих разделов не имеет:
страниц `/en/why/`, `/en/method/` и `/en/how/` не существует, а прятать
единственную ссылку не за чем. Страницы `/schools/` на английском тоже нет —
это решение, а не пропуск: см. `docs/open-questions.md`.

## Как посмотреть локально

```bash
python3 ../serve-site.py
```

Дальше http://127.0.0.1:8765 — страницы открываются по тем же адресам, что на
боевом сайте, несуществующий путь отдает `404.html`.

## Хостинг

Сайт отдает Timeweb Cloud (App Platform, тип Frontend): после отправки кода в
`main` он сам запускает `npm run build` и отдает папку `build/`. Настройки
приложения, подключение домена и переключение DNS описаны в `DEPLOY.md`.

## Что где

- `package.json`, `scripts/build.mjs` — сборка для Timeweb: копирует сайт в
  `build/`, служебные файлы (README, DEPLOY, CNAME и т. п.) туда не попадают
- `assets/site.css` — все стили, дизайн-токены в `:root`
- `assets/site.js` — мобильное меню, шапка при скролле, форма вейтлиста
- `assets/logo-*.svg` — логотип
- `assets/*.webp` + `assets/*.jpg` — фотографии. В разметке всегда пара:
  `<picture><source srcset="/assets/имя.webp" type="image/webp"><img src="/assets/имя.jpg" width height alt></picture>`.
  Браузер берет webp, jpg остается запасным. Добавляя новое фото, кладите оба
  файла с одинаковым именем и не забывайте `width`/`height` на `img` — без них
  верстка прыгает при загрузке
- `assets/og.jpg` — превью для мессенджеров и соцсетей (1200×630), прописано
  в `og:image` и `twitter:image` на всех страницах. Остается JPEG: часть
  соцсетей и мессенджеров не рисует webp в превью
- `assets/og-en.jpg` — то же превью для английских страниц
- `assets/og-source.html` и `assets/og-en-source.html` — вёрстка этих превью.
  Чтобы пересобрать: открыть файл в браузере, снять элемент `#og` при
  deviceScaleFactor 2 (получится 2400×1260) и уменьшить до 1200×630 в JPEG
  качества 92. Правки в раскладке вносите в оба файла сразу

Шрифты: **Jost** (заголовки и кнопки), **Wix Madefor Text** (текст, как в приложении), **Noto Sans**
(только транскрипция — в первых двух нет блока IPA). Лежат у нас в
`assets/fonts/` и подключаются через `/assets/fonts/fonts.css`, к Google Fonts
сайт не обращается: политика конфиденциальности обещает, что данные посетителей
не уходят за границу. Новое начертание — скачать woff2 с Google Fonts в эту же
папку и добавить `@font-face` в `fonts.css`, ссылку на fonts.googleapis.com не
ставить.
